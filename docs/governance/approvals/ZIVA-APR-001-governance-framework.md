## 1. Decisión

Se aprueba institucionalmente el contenido completo del Pull Request #1 para su incorporación al repositorio maestro de ZivaLatam, sujeto a los límites y exclusiones expresamente indicados en este registro.

La aprobación comprende:
- Marco de gobierno documental.
- Convenciones de commits.
- Modelo de trazabilidad.
- Procedimiento de revisión y aprobación.
- Procedimiento e índice de decisiones.
- Plantillas ADR y APR, aprobadas para su uso como plantillas.

## 2. Alcance y exclusiones

La aprobación autoriza el contenido documental para el gobierno interno del proyecto. No acredita:
- Constitución de una persona jurídica, representación legal frente a terceros ni facultades societarias.
- Revisión o certificación profesional independiente.
- Cumplimiento legal o regulatorio en jurisdicción alguna.
- Configuración activa de protección de ramas, controles automáticos, respaldos, firma, sellado de tiempo o archivo inmutable.
- Implementación o verificación de controles técnicos.
- Aprobación de decisiones de arquitectura, producto o negocio futuras.

Las plantillas se aprueban como instrumentos documentales; cada registro futuro deberá completarse y aprobarse por separado cuando corresponda.

## 3. Autoría, revisión y segregación

La autoría y la aprobación institucional se concentran actualmente en el mismo titular/responsable. Esta circunstancia se declara expresamente y no se presenta como revisión independiente. La aprobación institucional interna no sustituye una revisión profesional externa ni una revisión de GitHub por una persona distinta del autor cuando las reglas de GitHub o el nivel de riesgo la requieran.

## 4. Condiciones de integración

1. Incorporar únicamente el commit aprobado o una versión posterior que conserve el mismo contenido y alcance; cualquier cambio material requiere evaluación y, si corresponde, nueva aprobación.
2. Mantener claramente diferenciados los estados APROBADO, IMPLEMENTADO y VERIFICADO.
3. No declarar implementados controles por el solo hecho de aprobar o integrar los documentos.
4. Conservar el vínculo entre este APR, el PR, el commit SHA y la versión publicada.

## 5. Evidencia de autorización

Confirmación expresa del usuario en la conversación de trabajo del 2026-11-07: aprobación institucional del contenido completo de los PR #1 y #2, con las distinciones acordadas y sin declarar implementados controles aún no implementados.
