# Registro de decisiones

> **Estado:** EN DESARROLLO — procedimiento propuesto.

## Qué registrar

Usar un ADR (*Architecture Decision Record*) para decisiones relevantes, duraderas o difíciles de revertir, incluidas arquitectura, estándares, modelos de datos, seguridad, interoperabilidad, proveedores y criterios institucionales.

No todo comentario o tarea requiere un ADR. Las decisiones operativas menores pueden quedar documentadas en el Issue o Pull Request correspondiente.

## Convención

Identificador: `ZIVA-ADR-NNN`, con numeración secuencial y sin reutilizar números. Nombre de archivo recomendado: `ZIVA-ADR-NNN-titulo-breve.md`.

Estados permitidos: PROPUESTO, APROBADO, RECHAZADO, SUPERADO.

Una decisión solo pasa a APROBADO cuando la autoridad competente la confirma explícitamente y el registro de aprobación correspondiente queda vinculado.

## Índice inicial

No existen ADR institucionales aprobados en este expediente inicial. El primer ADR se creará cuando exista una decisión concreta que registrar.
