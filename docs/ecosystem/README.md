# Ecosistema e iniciativas

Esta área organiza las capacidades, productos, módulos e iniciativas relacionadas con ZivaLatam, diferenciando el ecosistema conceptual actual de los antecedentes históricos y del patrimonio creativo.

## Patrimonio creativo

- [Universo creativo de ZivaLatam](creative-assets/README.md) — universo narrativo incorporado por decisión declarada del fundador, con procedencia histórica ZAFU/ZafuPay, fuente de referencia, Biblia Maestra y registro de continuidad. Estado: borrador en revisión.

## Iniciativas históricas

- [BREGPersonal](historical-initiatives/bregpersonal.md) — antecedente conceptual y experimental; no es un producto actual aprobado ni una capacidad operativa de ZivaLatam.

## Criterios de mantenimiento

- No presentar iniciativas históricas como empresas constituidas o servicios productivos.
- Registrar por separado propósito, alcance, estado, evidencia y relación con ZivaLatam.
- No inferir continuidad técnica ni reutilización de código por similitud conceptual.
- Distinguir patrimonio creativo, productos, capacidades y entidades jurídicas.
- Incorporar nuevos expedientes solo cuando exista contenido sustantivo que conservar.
